## siv3d-practice リポジトリ運用法

このリポジトリは **Siv3D の練習コード共有** に使います。

### コード追加方法
- Visual Studio から新しいプロジェクトを追加し、コードを追加してください。

### ブランチ運用
- `main` へ直接コミットせず、 **新しいブランチを切ってからマージ** してください。

### プルリクエストについて
- プルリクには特に制限を設けていません。
- **自己責任でマージ**してください。

### コメントについて
- コード内にコメントが多いと読みやすいと思います。
- プライベートな開発なので、適当でいいのでコメントがあるとうれしいです。
