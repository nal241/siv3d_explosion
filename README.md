# (仮) タイトル

Siv3D ゲームジャム 2025 参加作品

## ゲームの概要

奥から迫りくる敵を、様々なアイテムを駆使して撃退する3Dアクションゲームです。
コンボを繋いでハイスコアを目指しましょう！

## 遊び方

画面下のボタンでスキルを選択して、敵を集めよう！<bt>
集まった敵に、爆弾を投げて一網打尽にしよう！<br>
一気に爆発させるとコンボがつながるよ<br>
コンボをつないで高得点を狙おう!

## アイテム紹介

| アイテム | 説明 |
|:---|:---|
| **ボム** | 投げると、周囲の敵にダメージを与え吹き飛ばします。 |
| **グラビティ** | 敵を一点に引き寄せる重力を発生させます。 |
| **フリーズ** | 一定時間、範囲内の敵の動きを止めます。 |
| **ウィンド** | 奥から手前に向かって強風を発生させ、敵を押し戻します。 |
